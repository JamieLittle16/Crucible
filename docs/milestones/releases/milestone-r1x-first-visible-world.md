Experimental Crucible milestone snapshot. This is not a production or playable server release.

The R1X milestone demonstrated that an unmodified Minecraft: Java Edition 26.2 client can complete Handshake -> Login -> Configuration -> Play through Crucible and render world data. The demonstrated Play bootstrap is an explicitly experimental finite replay fixture; captured replay data is not included in this release and is not production-admitted.

This release asset contains the `crucible-server` executable, MPL-2.0 licence, and repository README for the tagged source revision.
